## Практикум: функция как договор

**Цель:** отличать получение результата от печати и проверять функцию на конкретных входах.

```python
def discount(price, percent):
    return price * (100 - percent) / 100

final_price = discount(200, 15)
print(final_price)  # 170.0
```

Договор функции: принимает цену и процент, возвращает новую цену. `price` и `percent` — параметры; 200 и 15 — аргументы конкретного вызова.

**Проверь края:** скидка 0% сохраняет цену, 100% даёт ноль. Проверки допустимости отрицательной цены или процента больше 100 в этом коротком примере нет; для реальной программы её нужно спроектировать отдельно.

```python
def show_double(x):
    print(x * 2)

result = show_double(3)  # на экран: 6
print(result)           # на экран: None
```

Без выполненного `return` функция возвращает `None`. Печать не заменяет возвращаемое значение. После `return` выполнение текущего вызова завершается. Локальные имена внутри функции не становятся автоматически переменными вызывающего кода.

### Самопроверка

Напиши `is_even(n)`, возвращающую результат `n % 2 == 0`. **Разбор:** `return n % 2 == 0`, а не только `print(...)`. Тогда результат можно использовать в условии, сохранить или проверить в тесте.
