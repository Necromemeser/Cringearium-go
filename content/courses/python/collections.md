## Практикум: что именно мы меняем

**Цель:** выбирать между списком и словарём и понимать совместное обращение к изменяемому объекту.

```python
scores = [5, 7]
backup = scores
scores.append(9)
print(backup)  # [5, 7, 9]
```

Здесь оба имени указывают на один список. Для отдельной поверхностной копии списка простых чисел используй `backup = scores.copy()`. Это отличается от примера с переприсваиванием целого числа: список изменяется на месте.

| Потребность | Структура | Обращение |
| --- | --- | --- |
| Упорядоченные оценки | `[5, 7, 9]` | `scores[0]` |
| Оценка по имени | `{"Мира": 7}` | `marks["Мира"]` |

Индексация начинается с нуля; последний элемент — `scores[-1]`. Для списка длины 3 индекс 3 уже вне границ. `len(scores)` — количество элементов, а не последний допустимый индекс.

**Ловушка:** обращение к отсутствующему ключу `marks["Лев"]` вызовет `KeyError`. `marks.get("Лев", 0)` вернёт значение по умолчанию, но ноль здесь выбран программистом и не доказывает, что ученик получил нулевую оценку.

### Самопроверка

Для `items = [10, 20, 30]` назови `items[1]` и `items[-1]`. **Ответ:** 20 и 30. Для поиска цены по названию товара обычно удобнее словарь, а не список безымянных цен.
