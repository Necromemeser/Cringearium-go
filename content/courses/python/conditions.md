## Практикум: проверяй границы

**Цель:** понимать, какая ветка выполнится, и находить ошибки на границах диапазонов.

```python
score = 70
if score >= 90:
    grade = "отлично"
elif score >= 70:
    grade = "хорошо"
else:
    grade = "нужна практика"
print(grade)
```

В цепочке выполнится только первая подходящая ветка. Здесь ответ — «хорошо». Проверь баллы 69, 70, 89 и 90: именно соседние с границей значения чаще выявляют ошибку.

| Задача | Условие |
| --- | --- |
| От 0 до 100 включительно | `0 <= score <= 100` |
| И возраст, и доступ подходят | `age >= 16 and has_access` |
| Хотя бы один способ входа | `has_password or has_token` |

Если сначала написать `if score >= 70`, а ниже `elif score >= 90`, вторая ветка никогда не сработает: все баллы от 90 уже перехвачены первой.

**Типичная ошибка:** два самостоятельных `if` могут выполниться оба; `if` / `elif` выбирают одну ветку. `=` связывает имя со значением, `==` сравнивает значения. Отступ определяет, какие команды относятся к ветке.

### Самопроверка

Нужен бесплатный вход детям младше 7 лет. Подходит ли `age <= 7`? **Нет:** семилетние уже не младше 7. Проверяй 6, 7 и 8, а не только очевидный случай 3.
