## Практикум: калькулятор стоимости

**Цель:** отличать чтение строки от преобразования в число и выбирать операцию под задачу.

```python
price = int(input("Цена одной тетради: "))
count = int(input("Сколько тетрадей: "))
total = price * count
print("Итого:", total)
```

При вводе `15` и `3` получится 45. Если забыть `int`, выражение `price + count` склеит строки в `"153"`. А умножение двух строк вызовет `TypeError`.

![Путь данных: ввод → преобразование → вычисление → вывод](/images/python-data-pipeline.svg)

### Деление под задачу

Из 17 наклеек собирают наборы по 5: `17 // 5` — 3 полных набора, `17 % 5` — 2 оставшиеся наклейки. `/` даёт обычное деление, даже когда результат целый: `10 / 2` — `5.0`.

**Ловушка:** `int("3.5")` вызовет `ValueError`: строка не записана как целое число. `float("3.5")` даст 3.5. Преобразование `int(3.5)` даст 3, но это усечение, а не округление. В этих примерах десятичный разделитель — точка.

### Самопроверка

Как перевести 137 минут в часы и оставшиеся минуты? **Ответ:** `137 // 60` — 2 часа, `137 % 60` — 17 минут. Что произойдёт при вводе слова вместо числа? Программа потребует обработки неверного ввода; автоматического превращения текста в ноль нет.
