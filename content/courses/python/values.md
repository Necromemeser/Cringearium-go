## Практикум: предскажи значение, затем проверь

**После урока ты сможешь** проследить изменение переменной, различить `str`, `int`, `float`, `bool` и объяснить, почему одинаково выглядящие значения ведут себя по-разному.

| Выражение | Значение | Тип |
| --- | --- | --- |
| `7 + 2` | `9` | `int` |
| `"7" + "2"` | `"72"` | `str` |
| `7 / 2` | `3.5` | `float` |
| `7 > 2` | `True` | `bool` |

```python
score = 4
saved = score
score = score + 3
print(score, saved)  # 7 4
```

Присваивание не устанавливает вечную связь между именами. Здесь `saved` продолжает обозначать число 4. Справа от `=` сначала вычисляется выражение, затем результат связывается с именем слева.

**Типичная ошибка:** считать `"False"` логической ложью. Это непустая строка, а не значение `False`. В частности, `bool("False")` даёт `True`.

### Самопроверка без запуска

После `x = 8; y = x; x = 1` чему равны `x` и `y`? Почему `"3" * 2` и `3 * 2` дают разные результаты?

**Разбор:** `x` равен 1, `y` равен 8; повторение строки даёт `"33"`, числовое умножение — 6. Запусти примеры в Python 3 и сравни с прогнозом. Умение объяснить расхождение полезнее угадывания вывода.
